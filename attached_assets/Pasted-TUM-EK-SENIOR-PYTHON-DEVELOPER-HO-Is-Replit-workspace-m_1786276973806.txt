## SOURCE ARCHITECTURE (repo 1 — CipherElite)

## IMPLEMENTATION STEPS
1. Pehle git commit karke backup banao.
2. Copy karo (target repo me):
   - repo1/plugins → telegram_userbot/plugins (lekin plugins/bot.py ko DELETE karke naya likhna hai — step 6 dekho)
   - repo1/utils → telegram_userbot/utils (utils/thanos.py ko simple stub se replace karo: `def thanos_protect(s): return s`)
   - repo1/DB → telegram_userbot/DB
   - repo1/vars.py → telegram_userbot/vars.py
   - repo1/requirements.txt → flex-requirements.txt (install ke liye)
3. `telegram_userbot/config.py` me APPEND karo (existing vars mat hatao):
   - `Config` class: API_ID, API_HASH, BOT_TOKEN, MONGO_URI, GEMINI_API_KEY, BOT_NAME="FLEX FUCKER USERBOT", VERSION, BRANCH, UPSTREAM_REPO (target repo ka URL), OWNER_ID (env se), SUDO_USERS (env se), LOG_CHAT_ID (env se), STRING_SESSION (env ELITE_SESSION se alias — repo2 use nahi karta, sirf compatibility), DEFAULT_ALIVE_PIC / DEFAULT_PING_PIC / DEFAULT_PMPERMIT_PIC / ALIVE_NAME (env se, branded defaults).
   - Plugin ka import `from config.config import Config` resolve karne ke liye: loader me `sys.modules["config.config"] = <existing config module>` alias set karo. File-system folder mat banao jo existing `config.py` ko shadow kare.
4. Naya `telegram_userbot/plugin_loader.py` banao:
   - `async def load_for(userbot)` — ek UserbotClient instance leta hai.
   - Per-user fresh module loading, `asyncio.Lock` ke saath, taaki har user ke client par handlers register hon aur CMD_LIST per-user rahe.
   - Order: (a) `plugins/bot.py` ko fresh import karke `sys.modules["plugins.bot"]` set karo (CMD_LIST fresh), (b) `utils.utils.init_client(client)` call karke CipherElite global ko is user ke client par point karo, (c) baaki saare `telegram_userbot/plugins/*.py` load karo (`bot.py` aur `__init__` chhod kar): `mod.init(client)` + `await mod.register_commands()` agar exist kare, (d) error handling: ek plugin fail ho to sirf wo skip ho, (e) cleanup: loaded modules ko namespace se hatao taaki agli user ke liye fresh ho.
   - sys.modules me alias: "config.config" → existing config module (Config class ke saath).
5. `telegram_userbot/userbot/client.py` me chhota patch: `start()` me client start hone ke baad `from plugin_loader import load_for; await load_for(self)` — try/except me wrap karo (fail ho to bhi bridge/AI chalte rahein).
6. `telegram_userbot/plugins/bot.py` NAYA likho (repo1 wala mat use karo — usme inline assistant bot hai jo PTB bot se conflict karega):
   - `CMD_LIST = {}` global, `add_handler(plugin_name, commands, description)`.
   - `bot = None` (inline assistant disabled — BOT_TOKEN PTB ke paas hai).
   - `init_bot(client)` → return None.
   - `.help` aur `.help <plugin>` commands: CipherElite.on + rishabh decorator se, DIRECT REPLY (inline nahi), "FLEX FUCKER USERBOT" branding, 4000-char chunking, HTML parse_mode, help_ui.esc se escaping.
7. Inline plugins ko direct-reply me convert karo (jaise plugins/alive.py, ping): jinme `bot.inline_query(...)` / `.click(...)` use hota hai, unme `if bot is not None:` guard + fallback `event.reply(...)` lagao. Inline unavailable hone par direct reply aaye.
8. Dependencies: `flex-requirements.txt` se install karo. Version conflict ho to essential packages install karo (telethon, python-dotenv, aiohttp, requests, pillow, beautifulsoup4, yt-dlp, google-generativeai, openai, speedtest-cli, pyfiglet, gitpython, motor, pymongo, rich). Media plugins ke liye `.replit` ke nix packages me `ffmpeg` add karo (`openssl` ke saath) — .replit ka run command mat badlo.
9. Conflict check: repo1 ka `scan_conflicts.py` copy karke chalao (duplicate command patterns pakadne ke liye). Existing bridge ke Telethon handlers se clash ho to report karo.
10. Syntax check: `python -m compileall telegram_userbot` chalao.
